=== WP Chat ===
Requires at least: 5.8
Requires PHP: 7.4
Stable tag: 0.6.0
License: GPL-2.0-or-later

Minimizable one-on-one chat widget connecting visitors directly to a switchboard-chat backend.

== Description ==
The visitor's browser talks directly to the backend. This WordPress site stores no message content and no visitor data; only plugin settings are saved. The widget keeps a temporary random session token in the page's memory (no cookie) and the backend deletes the conversation when the chat ends, the page is closed, or after inactivity.

== Setup ==
1. Upload the wp-chat folder to wp-content/plugins and activate.
2. Settings > WP Chat: enter the backend HTTPS URL, the privacy contact and the privacy policy URL.
3. The backend must allow this site's origin (WEB_ALLOWED_ORIGINS).

== Language ==
The widget has French and English texts and, by default, follows the visitor's browser language (French if the browser prefers French, otherwise English). Settings > WP Chat > "Widget language" can also follow the site language or force French or English. Texts you customize (respondent name, retention sentence) are shown as typed in every language.

== Where the chat appears ==
Settings > WP Chat > "Show the chat on": all pages (default) or only the pages you tick, optionally also on blog posts.

== Privacy ==
No third-party scripts, fonts or analytics. Suggested privacy-policy text is registered under Settings > Privacy.

== Description (français) ==
Fenêtre de clavardage réductible, en tête-à-tête, qui relie directement les visiteurs à un serveur switchboard-chat. Le navigateur du visiteur parle directement au serveur. Ce site WordPress ne stocke aucun contenu de message ni aucune donnée sur les visiteurs; seuls les réglages du module sont enregistrés. Le module garde un jeton de session aléatoire temporaire dans la mémoire de la page (aucun témoin) et le serveur supprime la conversation à la fin du clavardage, à la fermeture de la page ou après un délai d'inactivité.

== Installation (français) ==
1. Téléversez le dossier wp-chat dans wp-content/plugins et activez le module.
2. Réglages > WP Chat : entrez l'URL HTTPS du serveur, la personne responsable de la protection des renseignements personnels et l'URL de la politique de confidentialité.
3. Le serveur doit autoriser l'origine de ce site (WEB_ALLOWED_ORIGINS).

== Langue (français) ==
Le module a des textes en français et en anglais et, par défaut, suit la langue du navigateur du visiteur (français si le navigateur préfère le français, sinon anglais). Réglages > WP Chat > « Langue du clavardage » permet aussi de suivre la langue du site ou d'imposer le français ou l'anglais. Les textes que vous personnalisez (nom du répondant, phrase sur la conservation) sont affichés tels que saisis, dans toutes les langues.

== Où le clavardage apparaît (français) ==
Réglages > WP Chat > « Afficher le clavardage sur » : toutes les pages (par défaut) ou seulement les pages cochées, éventuellement aussi les articles de blogue.

== Confidentialité (français) ==
Aucun script, aucune police ni aucune analytique de tiers. Un texte de politique de confidentialité suggéré est enregistré sous Réglages > Confidentialité.
