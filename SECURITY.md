# Security policy

WP Chat is the website side of a confidential chat between people in distress and helpline respondents.
Please report security problems privately so they can be fixed before they are known.

## Reporting a vulnerability

- Use GitHub's **private vulnerability reporting**: the "Security" tab of this repository, then
  "Report a vulnerability". Do not open a public issue, pull request or discussion.
- Include what you found, how to reproduce it, and what an attacker could do with it.
- Never include real conversations, phone numbers or credentials, yours or anyone else's.

You should get an answer within 7 days. Once a fix is released the advisory is published, with credit to
you if you want it.

## Supported versions

Only the latest release (and the `main` branch) is supported.

## Scope

In scope: the plugin in `wp-chat/` (settings page, widget JavaScript, what it stores in WordPress and in the
visitor's browser). Out of scope: WordPress itself, other plugins and themes, and the chat server
([SwitchBoardChat](https://github.com/Switchboarders/SwitchBoardChat): report there).

# Politique de sécurité

WP Chat est le côté site Web d’un clavardage confidentiel entre des personnes en détresse et les répondants
d’une ligne d’écoute. Signalez les problèmes de sécurité en privé, pour qu’ils soient corrigés avant d’être
connus.

- Utilisez le **signalement privé de vulnérabilité** de GitHub : onglet « Security » de ce dépôt, puis
  « Report a vulnerability ». N’ouvrez pas de signalement, de demande de fusion ni de discussion publics.
- Décrivez ce que vous avez trouvé, comment le reproduire et ce qu’un attaquant pourrait en faire.
- N’y mettez jamais de vraies conversations, de numéros de téléphone ni d’identifiants.

Vous recevrez une réponse en 7 jours au plus. Seule la dernière version (et la branche `main`) est maintenue.
Hors du périmètre : WordPress, les autres modules et thèmes, et le serveur de clavardage
([SwitchBoardChat](https://github.com/Switchboarders/SwitchBoardChat) : signalez-le là).
